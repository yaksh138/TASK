MERN Stack

MERN Stack is a full-stack web development technology that uses MongoDB for the database, Express.js for the backend framework, React.js for the frontend user interface, and Node.js as the runtime environment. It allows developers to build fast, scalable, and modern web applications using JavaScript from frontend to backend.

Python Full Stack

Python Full Stack Development is the process of building complete web applications using Python for the backend, HTML, CSS, and JavaScript for the frontend, and a database such as MySQL or PostgreSQL. A Python Full Stack Developer can develop both the client-side and server-side of a web application.

1. Preparation

  • Learn HTML
  • Learn CSS
  • Learn JavaScript
  • Learn Python Basics
  • Learn Django or Flask
  • Learn SQL (MySQL/PostgreSQL)
  • Learn Git & GitHub
